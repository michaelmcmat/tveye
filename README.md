# tveye

Маленький браузер для Android TV: свежий движок Firefox (GeckoView), управление пультом, блокировка рекламы
и ничего лишнего. Сделан для старых телевизоров на Android 8–9, где системный WebView (Chrome) больше
не обновляется.

## Что внутри

- **Движок** — GeckoView от Mozilla, та же версия, что в текущем Firefox. Берётся с maven.mozilla.org,
  при каждой сборке сверяется с опубликованной Mozilla контрольной суммой.
- **Блокировка рекламы** — встроенный uBlock Origin Lite (подписан Mozilla, сверяется с контрольной суммой
  GitHub). Выключается щитом на панели: на слабых ТВ без него первая страница после запуска открывается быстрее.
- **Пульт** — стрелки двигают курсор (с ускорением при удержании), ОК — клик, у края экрана и кнопками CH+/CH−
  страница прокручивается, «Назад» — назад или выход из полноэкранного видео, долгое «Назад» — стартовая
  страница, Play/Pause управляет видео.

## Защита

- Только `https://` (для сайтов без него — страница Firefox «продолжить всё равно»), строгая защита от слежки,
  сторонние cookie изолированы, трекинговые параметры из ссылок вырезаются.
- Приватный режим: история, cookie и кеш не сохраняются после закрытия. Хранятся только закладки.
- Сайты не могут открывать другие приложения (`intent:`, `market:` и т. п.), скачивать файлы, обращаться
  к устройствам домашней сети, просить камеру, микрофон, местоположение или уведомления.
- Всплывающие окна на чужие сайты блокируются; сайт не может сам, без нажатия ОК, увести на другой домен.
- Разрешения приложения: интернет, состояние сети, удержание экрана во время видео, установка собственных
  обновлений и громкость (нужна движку для видео). Камеры, микрофона, файлов и местоположения нет.

## Обновления

Раз в неделю GitHub Actions проверяет, вышли ли новый GeckoView или uBlock Origin Lite (не моложе 3 дней),
собирает tveye, проверяет движок, блокировщик и подпись и публикует релиз. tveye на ТВ раз в 6 часов смотрит
последний релиз этого репозитория и показывает «Доступно обновление». Перед установкой он сверяет
контрольную сумму, опубликованную GitHub, и подпись APK со своей; затем Android ещё раз проверяет подпись,
и обновление подтверждается кнопкой ОК.

Ключ подписи хранится только в секретах репозитория (`TVEYE_KEYSTORE_B64`, `TVEYE_STORE_PASSWORD`,
`TVEYE_KEY_ALIAS`, `TVEYE_KEY_PASSWORD`) и в локальной папке `../tveye-secrets/`. Если его потерять, обновления
перестанут ставиться поверх — понадобится удалить и установить tveye заново.

## Сборка вручную

Нужны JDK 17 и Android SDK (платформа 37.2, build-tools 36):

```
./gradlew assembleRelease -PtveyeUpdateRepo=<владелец>/tveye
```

Подпись берётся из `../tveye-secrets/signing.properties` или из переменных `TVEYE_KEYSTORE`,
`TVEYE_STORE_PASSWORD`, `TVEYE_KEY_ALIAS`, `TVEYE_KEY_PASSWORD`.
